



Navigate to project folder
Open worm game folder
Open assets folder
Open worm code with VScode
If the game does not automatically start after vscode has been opened, press the triangle start icon to start the game
If the game does not start when clicking the triangle icon, press Control + Shift + P, then type "Python Select interpreter" Choose Python 3.12.10
If problems persist, In VSCode navigate to 'File" then select "Open folder" and select the "assets folder" inside the Project folder
Tested environment : Windows 11, Python 3.12.10 , Vscode
