1.Download Zip 
2.Unzip the downloaded folder
3.Navigate to project folder inside unzipped folder
4.Open worm game folder
5.Open assets folder
6.Open worm code with VScode
7.If the game does not automatically start after vscode has been opened, press the triangle start icon to start the game
8.If the game does not start when clicking the triangle icon, press Control + Shift + P, then type "Python Select interpreter" Choose Python 3.12.10
9.If problems persist, In VSCode navigate to 'File" then select "Open folder" and select the "assets folder" inside the Project folder
10.Tested environment : Windows 11, Python 3.12.10 , Vscode
